# دورة مشتريات ودورة مبيعات كاملة (بأسلوب Odoo) لتجارة الأعلاف

الهدف: تحويل الشاشات الحالية (أمر شراء واحد + فاتورة مبيعات مباشرة) إلى دورتين كاملتين متسلسلتين بنفس منطق Odoo، مع مرونة كاملة مع النظام المصري (ضريبة 14%، خصم وحسم تحت حساب الضريبة، البطاقة الضريبية، الفاتورة الإلكترونية كحقول اختيارية).

## دورة المشتريات (Procure to Pay)

```text
طلب عرض سعر  →  أمر شراء  →  إذن استلام (وزن فعلي)  →  فاتورة مورد  →  دفع
   RFQ            PO            GRN                     Bill          Payment
                                  ↓
                        مرتجع مشتريات / إشعار مدين
```

المراحل والقواعد:
1. **طلب عرض سعر (RFQ)**: مورد + أصناف + كميات، بدون أثر مخزني أو مالي. مقارنة أسعار أكثر من مورد لنفس الطلب واختيار الأفضل.
2. **أمر الشراء**: يتولّد من الـ RFQ بضغطة واحدة (أو يُنشأ مباشرة). حالات: مسودة → معتمد → مستلم جزئياً → مستلم بالكامل → مقفل / ملغي. لا أثر محاسبي حتى الاستلام.
3. **إذن الاستلام (GRN)**: يقبل **استلام جزئي متعدد** من نفس الأمر مع تتبع "المطلوب / المستلم / المتبقي". إدخال الوزن الفعلي (وزن قائم/فارغ/صافي) وحساب **فرق الوزن** مقابل المطلوب، ونسبة سماح قابلة للضبط. يُحدّث المخزون فوراً ويُنشئ قيد: مدين مخزون / دائن فواتير مشتريات لم تُستلم.
4. **مصاريف الشراء (تكلفة الوصول)**: نولون/نقل/تحميل/شكارة تُوزّع على الأصناف بالوزن أو بالقيمة وتدخل في متوسط التكلفة المرجح.
5. **فاتورة المورد**: تُولّد من الاستلامات (وليس من الأمر) مع **مطابقة ثلاثية** (أمر / استلام / فاتورة) ورفض الفرق خارج نسبة السماح. تحتسب 14% ضريبة + **خصم وحسم** (نسبة قابلة للضبط) وتُنشئ قيد المشتريات والضريبة والذمم الدائنة.
6. **الدفع**: دفع كلي/جزئي نقدي أو بنكي أو شيك، مربوط بالفاتورة مع تحديث الرصيد وتسوية الشيكات.
7. **مرتجع المشتريات**: يخرج المخزون ويُنشئ إشعار مدين على المورد.

## دورة المبيعات (Order to Cash)

```text
عرض سعر  →  أمر بيع  →  إذن صرف/تسليم  →  فاتورة بيع  →  تحصيل
Quotation     SO          Delivery          Invoice       Receipt
                              ↓
                     مرتجع بيع / إشعار دائن
```

المراحل والقواعد:
1. **عرض سعر للعميل**: بصلاحية سارية حتى تاريخ، تحويل بضغطة إلى أمر بيع.
2. **أمر البيع**: حجز الكمية في المخزن (رصيد متاح = الفعلي − المحجوز) مع **فحص حد الائتمان** للعميل ومنع التجاوز أو التحذير.
3. **إذن الصرف/التسليم**: تسليم جزئي متعدد، وزن فعلي عند الميزان، رقم سيارة/سائق، خروج المخزون وقيد تكلفة المبيعات.
4. **فاتورة البيع**: تُولّد من التسليمات، تدعم فاتورة نقدية (تجزئة) وفاتورة ضريبية للشركات/المزارع، 14% ضريبة، خصم سطر ونسبة/قيمة، حقول الفاتورة الإلكترونية المصرية (كود الصنف GS1/EGS، وحدة القياس، الرقم الضريبي) **اختيارية وقابلة للتفعيل**.
5. **التحصيل**: نقدي/بنكي/شيك، كلي أو جزئي، مع تحديث أرصدة الفواتير وأعمار الديون.
6. **مرتجع البيع**: إرجاع للمخزون + إشعار دائن لا يتجاوز قيمة الفاتورة الأصلية.

## المرونة مع الأنظمة المصرية

- الضريبة على القيمة المضافة 14% قابلة للضبط لكل صنف (خاضع / معفى / صفري) — كثير من خامات الأعلاف معفاة.
- **خصم وحسم تحت حساب الضريبة** بنسب قابلة للتحديد على فواتير الموردين والعملاء.
- **دمغة** اختيارية، وحقول البطاقة الضريبية والسجل التجاري تظهر على المستندات.
- ترقيم مستندات متسلسل لكل نوع (RFQ / PO / GRN / SO / DO / INV / RET) بمنع تكرار نهائي.
- كل الأرقام والتواريخ بالصيغة الإنجليزية والعملة جنيه مصري، وكل الشاشات تعمل أوف لاين مع المزامنة التلقائية.

## الشاشات الجديدة في السايد بار

- **المشتريات**: طلبات عروض الأسعار، أوامر الشراء، إذون الاستلام، فواتير الموردين، مرتجعات المشتريات، مصاريف الشراء، تقرير متابعة دورة الشراء.
- **المبيعات**: عروض الأسعار، أوامر البيع، إذون الصرف/التسليم، فواتير البيع، مرتجعات البيع، تقرير متابعة دورة البيع (من الأمر للتحصيل).
